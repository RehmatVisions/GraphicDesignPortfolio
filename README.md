# Ultra-Modern Graphic Designer Portfolio

A stunning, fully animated portfolio website designed for female graphic designers with a beautiful pinkish theme.

## ✨ Features

### Design & Aesthetics
- **Pinkish Theme**: Soft, elegant pink gradient backgrounds with purple accents
- **Glassmorphism Effects**: Modern frosted glass card designs
- **Smooth Animations**: Fade-in, slide-up, and hover effects throughout
- **Particle Background**: Animated floating particles for visual depth
- **Dark/Light Mode**: Toggle between themes with smooth transitions

### Sections

1. **Hero Section**
   - Full-screen gradient background
   - Animated profile picture with glow effect
   - Floating creative icons
   - Smooth scroll indicator
   - Parallax effect

2. **About Section**
   - Animated circular profile image
   - Fun fact counters (projects, clients, awards)
   - Downloadable resume button
   - Scroll-triggered animations

3. **Skills Section**
   - Circular progress indicators
   - Animated skill bars
   - Hover effects with tooltips
   - Tools: Photoshop, Illustrator, Figma, After Effects

4. **Portfolio Section**
   - Filterable project grid (All, Branding, Illustration, Web Design)
   - Hover overlay effects
   - Modal lightbox for project details
   - Smooth transitions

5. **Testimonials Section**
   - Carousel slider with client reviews
   - Auto-slide functionality
   - Star ratings
   - Client photos and info

6. **Contact Section**
   - Floating label form inputs
   - Form validation
   - Animated submit button
   - Social media links (Instagram, Behance, Dribbble, LinkedIn)

### Additional Features
- Scroll-to-top button with glow effect
- Smooth scrolling navigation
- Fully responsive design
- Custom scrollbar styling
- Optimized performance
- Accessibility compliant

## 🚀 Quick Start

1. Open `index.html` in your browser
2. Customize the content:
   - Replace `[Your Name]` with your actual name
   - Update profile images (replace placeholder URLs)
   - Add your project images and details
   - Update social media links
   - Modify colors in CSS variables if needed

## 🎨 Customization

### Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --primary-pink: #ff69b4;
    --secondary-pink: #ff1493;
    --light-pink: #ffb6c1;
    --dark-pink: #c71585;
    --purple: #9370db;
}
```

### Content
- **Profile Images**: Replace placeholder URLs in HTML
- **Projects**: Update `projectData` object in `script.js`
- **Skills**: Modify skill percentages in HTML `data-percent` attributes
- **Testimonials**: Edit testimonial cards in HTML
